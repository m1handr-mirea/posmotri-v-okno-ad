# Посмотри в окно

Учебный проект Яндекс Практикума — интерактивное веб-приложение для просмотра видео из разных городов мира с фильтрацией по названию города и времени суток.

## Ссылка на репозиторий

https://github.com/m1handr-mirea/posmotri-v-okno-ad

## Реализованная функциональность и вёрстка

- Центрированная двухколоночная сетка (`.page`, `.content`, `.result`, `.content__details`) на Flexbox.
- Видеоплеер и контейнер видео с корректным позиционированием прелоадеров и ошибок.
- Форма поиска с кастомным текстовым полем, стилизованными чекбоксами и состояниями `:hover`, `:active`, `:focus-visible`.
- Прокручиваемый список видеокарточек с кастомным скроллбаром, обрезкой заголовков и описаний, выделением активной карточки и кнопкой «Показать ещё».
